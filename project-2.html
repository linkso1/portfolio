项目简介

实时数据仪表盘是一个面向企业级用户的数据可视化平台，旨在将复杂的数据转化为直观、可交互的图表和报表。该平台支持多种数据源接入，通过 WebSocket 实现数据的实时推送与更新，让决策者能够第一时间掌握业务动态。

前端采用 Vue.js 构建，结合 D3.js 实现高度自定义的数据可视化图表。后端使用 Python (FastAPI) 处理数据聚合与分析逻辑，支持 RESTful API 和 WebSocket 双通道通信。系统内置权限管理模块，支持细粒度的数据访问控制，确保企业数据安全。

技术架构

Vue.js

前端框架，Composition API，Pinia 状态管理，组件化开发

D3.js

数据可视化库，自定义 SVG 图表，丰富的交互与动画效果

WebSocket

实时双向通信，数据推送延迟低，支持断线自动重连

Python

FastAPI 后端框架，高性能异步处理，pandas 数据分析

核心功能

多数据源接入

支持 MySQL、PostgreSQL、MongoDB、REST API 等多种数据源，统一数据接口层

自定义图表

拖拽式图表配置，支持折线图、柱状图、饼图、热力图等 50+ 图表类型

实时告警

基于阈值的智能告警，支持邮件、短信、钉钉等多渠道通知推送

权限管理

基于角色的访问控制（RBAC），支持仪表盘级别和组件级别的细粒度权限

报表导出

支持 PDF、Excel、PNG 等格式的报表导出，定时自动生成并发送

仪表盘布局

可拖拽的网格布局系统，支持自由调整图表大小和位置，保存多套布局方案
